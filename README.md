# Throughit Web Application  
#### A platform to help students manage assignments and deadlines effectively, May 2025  
#### By **Isaac Gitumbi**

## Description  
Throughit is a platform designed to help students manage their assignments and deadlines effectively.  
The goal is to simplify the assignment management process, allowing students to focus on their studies.  

It provides a simple interface for inputting assignment details, challenges, deadlines, and includes a timer to help students stay focused while working.  

## Setup/Installation Requirements  
* No installation required  
* Simply download or clone the repository  
* Open the `home.html` file in any modern web browser  
* All features (form submission, timer, etc.) run entirely in the browser using vanilla JavaScript
